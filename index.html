Complete 5-Module Deliverables Scope

A cohesive ecosystem comprising 4 purpose-built frontends and 1 high-speed backend engine.

Customer Experience

Customer App & Responsive Web

Native-feel cross-platform ordering application (Flutter Android/iOS) and desktop/mobile web portal.

  • OTP login & customer profile with saved addresses
  • GPS-based restaurant discovery & radius filtering
  • Restaurant menu categories, veg/non-veg tags, variants & add-ons
  • Live shopping cart, cooking instructions & coupon codes
  • Online payment (Razorpay/Cashfree/UPI) & Cash on Delivery
  • Real-time order state tracker & order history reorder
Merchant System

Restaurant Management Portal

Web & tablet-friendly dashboard designed for fast kitchen order processing and catalog control.

  • Loud sound notification alerts for new incoming orders
  • 1-Tap order Accept / Reject with food preparation timer
  • Live menu manager (edit prices, item status, out-of-stock toggle)
  • Add-on and customization pricing management
  • Store operating hours & online/offline store switch
  • Daily sales and completed order summaries
Logistics & Fleet

Delivery Partner Android App

Streamlined mobile application for riders to receive assignments and navigate pickups/deliveries.

  • Rider online/offline availability switch
  • Real-time delivery assignment broadcast notifications
  • Order pickup from restaurant & customer delivery directions
  • 1-Tap navigation launcher (Google Maps route)
  • Customer contact via masked call/direct link
  • OTP verification to confirm delivery completion
Master Control

Central Admin Dashboard

Complete administrative oversight over all transactions, restaurants, riders, and platform commissions.

  • Real-time live monitoring of all active platform orders
  • Commission % rule configuration per restaurant
  • Delivery fee calculation settings (distance/flat slab)
  • Restaurant KYC document review & activation controls
  • Rider onboarding and manual dispatch override
  • Financial payout reports & daily/weekly sales analytics
Core Engine

Backend API & Database

Secure, scalable server architecture built with clean micro-routing and optimized geospatial indexing.

  • Node.js / Express or NestJS REST API architecture
  • PostgreSQL + PostGIS for lightning-fast radius geo-queries
  • WebSockets for sub-second status changes and live kitchen alerts
  • Role-Based Access Control (RBAC) & JWT authentication
  • Webhooks for Razorpay/Cashfree payment reconciliation
  • Containerized Docker deployment configuration
