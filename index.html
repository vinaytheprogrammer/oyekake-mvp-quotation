Swiggy / Domino's-Grade Live Tracking Engine

How real-time location streaming is engineered to deliver a seamless consumer experience while preventing runaway Google Maps API bills.

The 5-Stage Live Order Lifecycle

Customers experience an interactive step-by-step visual tracker backed by real-time WebSockets. When the rider picks up the food, the map transforms into a live moving vehicle view showing estimated time of arrival (ETA).

1
Order Placed
Payment confirmed; restaurant alerted with live chime.
2
Food Preparing
Kitchen confirms order and estimated prep timer.
3
Rider Assigned
Rider navigates to restaurant to collect package.
4
Out for Delivery
Live moving bike on map with real-time ETA.
5
Delivered
Customer provides OTP to rider; order marked complete.
Cost-Engineered Architecture: Traditional apps burn thousands of dollars querying Google Directions API every 3 seconds. Our engine streams raw coordinates over lightweight WebSockets with client-side bearing interpolation. This achieves smooth, realistic vehicle motion while keeping map API usage firmly within the Google Maps $200 free monthly allowance (~₹0 cost).

Launch Focus: Single City & Scaling Roadmap

Phase 1 is strictly geo-fenced to One Target City to guarantee operational profitability, with an architecture ready to scale statewide and nationally.

Why Single-City Focus in Phase 1?

Focusing initial launch on 1 city keeps operational density tight, delivery times under 30 minutes, and infrastructure costs below ₹1,000/month. The software code is written with a database architecture (`city_id` and `zone_polygon` indexing) so that adding City #2, #3, or #50 requires zero code rewrites—only an admin toggle.

Expansion Tier Geographic Footprint Technical Scaling Mechanism Estimated Cloud Infrastructure Cost
Phase 1: Launch (MVP) 1 Focus City (Current Scope) Single High-Performance VPS + PostgreSQL PostGIS + WebSockets ~₹500 – ₹1,000 / month (Billed to client directly)
Phase 2: Regional (3–5 Cities) 3–5 Nearby Cities / Districts Redis Cache Layer for Rider Location Pub/Sub + Database Read Replicas ~₹3,500 – ₹6,000 / month (Low overhead)
Phase 3: State / National (20+ Cities) Multi-State / Pan-India Docker/Kubernetes Cluster + Kafka/RabbitMQ Event Bus + Automated Dispatch Batching ~₹15,000 – ₹35,000 / month (Self-funded by high GMV)
